# waqtfinance-web

Official web platform and API integration for Waqt Finance.

## Features
- Direct Lead Generation & Instant Loan Flow (Steps 1 to 6)
- Aadhaar DigiLocker Verification Integration (Digitap API)
- PAN & CRIF High Mark CIBIL Credit Assessment (Digitap Bureau API)
- Business Proofs: GSTIN, Udyam Verification, Shop / Business Premises Live Camera Capture & Upload
- Bank Verification: RBI Account Aggregator (AA) Integration (Digitap Bank Data UI API v1.21)
- Administrative Control Panel & Master Loan Processing
